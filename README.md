# Math Tower Adventure

A fun and educational tower-climbing math game designed for elementary school students!

## 🎮 Game Features

- **10 Exciting Levels**: Battle through progressively harder monsters
- **3 Unique Character Classes**:
  - 🛡️ **Warrior**: Take less damage (0.5 HP) on wrong answers
  - 🧙 **Mage**: Double damage every 3 correct answers
  - 🏹 **Archer**: Faster gameplay with 5 seconds less per question
- **Engaging Math Problems**: Addition, subtraction, and multiplication
- **Reward Layers**: Special rewards at levels 5 and 9
- **Leaderboard System**: Track top 15 players with detailed stats
- **Child-Friendly UI**: Beautiful animations and responsive design

## 🎯 How to Play

1. Select your character class
2. Answer math questions correctly to defeat monsters
3. Progress through 10 levels to reach the Demon King
4. Collect rewards at special levels
5. Try to achieve the fastest time and highest accuracy!

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build

# Preview production build
npm run preview
```
